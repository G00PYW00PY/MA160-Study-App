# MA160 Linear Algebra Study App

A standalone study tool for MA160 exam preparation.

* **Requires:** David Poole, *Linear Algebra: A Modern Introduction*, 3rd Edition, Cengage Learning.

## How to Download & Run

1. Look at the **Releases** section on the right side of this page.
2. Download the version for your computer (`.zip` file).

### For Windows:
1. Extract the `.zip` file.
2. Double-click **MA160_Study_App.exe** to launch.

### For Mac:
1. Extract the `.zip` file to get the **MA160StudyApp.app** folder.
2. **Important:** Because I am a student developer, macOS will block the app initially. 
3. **Right-click** (or Control-click) the app icon and select **Open**. 
4. Click **Open** again on the security prompt. You only need to do this once!

## Troubleshooting

* **"Windows protected your PC":** Click **More Info** and then **Run Anyway**.
* **"App is damaged" or "Cannot be verified" (Mac):** This happens because the app isn't signed by an Apple Developer account. Use the **Right-click -> Open** method described above to bypass the security check.
* **Antivirus:** If your antivirus deletes the file, you may need to temporarily disable it or add an exception for the folder.
